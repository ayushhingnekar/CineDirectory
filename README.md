# CineDirectory 🎬

**CineDirectory** is a sleek and responsive movie guide web application built to help users discover their next favorite film. This project was developed to gain practical hands-on experience with core frontend technologies, focusing on creating a professional-grade User Interface (UI).

[CineDirectory Screenshot] (posters/Screenshot 2026-02-18 161823.png)

## 🚀 Features

* **Cinematic Hero Slider:** A high-definition, interactive banner showcasing the latest blockbusters.
* **Dynamic Categories:** Organized sections for "Trending Now," "New Releases," and "Top Rated" films.
* **Responsive Design:** Fully optimized for desktops, tablets, and mobile devices.
* **Mood-Based Discovery:** (Optional: Add this if you implemented the mood filter we discussed!)
* **Custom Favicon:** Branded tab icon for a professional browser experience.

## 🛠️ Tech Stack

* **HTML5:** Structured the semantic content and movie data containers.
* **CSS3:** Implemented Flexbox/Grid layouts, custom animations, and a midnight-blue cinematic theme.
* **JavaScript:** Handled the image slider logic, search functionality, and dynamic UI updates.
